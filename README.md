# Diagram+

Web app แบบ client-side ล้วน สำหรับสร้างแผนผังเชิงโครงสร้างความคิด (mindmap, fishbone, logic model) ใช้ในงานตรวจสอบและวางแผนขององค์กร

ไม่มี server, ไม่มีบัญชีผู้ใช้ ข้อมูลอยู่ในเครื่องผู้ใช้ 100%
